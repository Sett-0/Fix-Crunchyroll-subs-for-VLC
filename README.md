# Fix Crunchyroll subs for VLC
## About
This script fixes text distortion issues in Crunchyroll subtitles when played in VLC media player. It works by adding missing tags at the beginning of the file that Crunchyroll stopped including a while ago.
\
This script is set to work with *.ass files. I don't know if it is useful with any other file formats.
## Usage
Just put the script file in the same directory as the subtitles and then run it.
